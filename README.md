# RTX 50 系列顯卡價格走勢

以原價屋（coolpc）線上估價單在 Wayback Machine 的歷史存檔為資料來源，重建 RTX 50 系列
各型號在台灣的掛牌價走勢。

**線上版：<https://vincent81614.github.io/rtx50-price-chart/>**

| 檔案 | 內容 |
|---|---|
| `index.html` | 完整獨立網頁，資料已內嵌，無外部相依，雙擊即可開啟 |
| `prices.json` | 型號層級：每個取樣日的最低／中位／最高價、可成交款數、缺貨與限搭機比例 |
| `skus.json` | 逐張卡：263 個品項、品牌、每個取樣日的價格，以及 MSRP 對照表 |

## 資料範圍

- 期間 2025-01 至今，取樣點為存檔日期，**非每日連續**，各月密度 2～24 次不等。
- 共 161 份含 RTX 50 資料的去重快照，合併為 131 個取樣日；最新一天直接擷取原價屋線上頁面
  （Wayback 通常落後一到兩天）。
- 全期 24,134 筆掛牌報價。

## 只計入「可成交」掛牌

原價屋估價單上很多品項看得到價格卻買不到。把它們算進統計會讓圖表說謊，因此依掛牌文字分類：

| 類別 | 字樣 | 處理 |
|---|---|---|
| 沒貨 | 售罄／完售／已售完／未到貨／勿訂／缺貨 | 排除 |
| 不接網路單 | 極缺／不收網單 | 排除 |
| 限搭整機 | 限組裝／限搭機／搭機優惠 | 排除 |
| 需洽門市 | 洽詢／門市供應／限門市 | 排除 |
| 限購數量 | 限購／每人一片／單購限一片 | 保留（仍可買） |

24,134 筆中 **82.7%** 屬可成交。某型號某日若完全沒有可成交掛牌，不會刪掉該日，
而是退回掛牌價並在圖上畫成**虛線**。

這一項影響很大：不做這層過濾的話，RTX 5090 的歷史最低會顯示為 $71,990（＝MSRP），
看起來 2025 年 2～6 月有四個月能用建議售價買到，實際上那段期間掛這個價的品項全是
「售罄」「極缺不收網單」「詳情請門市洽詢」，一天都沒真的能買。可單買的歷史最低是
**2025-08-30 的 $78,888**。另外，2026 年 2 月起 5090 沒有任何一天存在可直接單買的掛牌。

## 其他處理

- **型號分類不靠商品名稱**，改用頁面本身的 `<OPTGROUP LABEL='NVIDIA RTX5080-16GB(GDDR7)'>`
  分組，所以商品名前面會變動的行銷前綴（`[不漲！限搭機]`、`【組合優惠】`）不影響分類。
- **同日去重用正規化後的卡名**，不是完整掛牌字串——同一張卡可能在同一天出現兩次
  （多一個「熱賣」標記，或同時掛現金價與搭機價）。
- **排除**：加購配件（`[5080電源加購專案]加購 微星 MPG A850G 850W, $3990`）、
  買卡送遊戲的贈品公告、顯卡＋電源／＋SSD 組合包、外接顯卡盒（AI BOX）、整機、筆電、Quadro。
- 折扣價 `$29300↘$27900` 取後者。
- 卡名正規化：統一 `RTX 5060 Ti`／`RTX5060Ti`／`RTX5060 Ti` 三種寫法，剝掉規格括號與
  庫存尾註，「映眾」併回 INNO3D。1,888 個原始名稱 → 263 張卡。

## 限制

- 統計的是「該日在架可成交 SKU 的價格分佈」，不是追蹤同一張卡。**最低價這條線天生會抖**
  ——最便宜那款一下架，最低價就跳到次便宜的，看起來像漲價。看趨勢請用中位數。
- 「可成交」是依掛牌文字判定，不是實地查證；原價屋用字不完全一致，邊界案例可能誤判。
- 虛線區段代表該日完全沒有可成交掛牌。5090 有 68% 的取樣日屬此類，5080 27%、
  5070 Ti 18%、5070 12%，其餘型號 ≤2%。
- 只反映原價屋一家通路，不等於全台均價。下單前請以店家實際報價為準。
